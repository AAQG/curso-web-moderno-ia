### Web Moderno con IA
Curso basado en el uso de la inteligencia artificial como ayuda en la creacion de proyectos WEB.
 
## Que espero de este curso?
Espero poder aprender a utilizar la inteligencia artificial como una herramienta para la creacion de proyectos WEB. 

## Que no espero de este curso?
No espero que la inteligencia artificial haga todo el trabajo, sino que me ayude a ser mas eficiente en mi trabajo.

## Que tipo de proyectos WEB vamos a realizar?
Vamos a realizar proyectos WEB que utilicen las tecnologias mas recientes y modernas, incluyendo inteligencia artificial.
